# OSC_Fa21
This project proposes a new approach to measuring the amount of meaning that can be inferred from a stem in a complex word (i.e., TRUST in TRUSTWORTHY is more meaningful than WHISK in WHISKER). The metric, referred to as "cluster-centered Orthographic-Semantic Consistency" or cluster-centered OSC is then used to design stimuli for a priming experiment, and response data from this experiment are analyzed to demonstrate that cluster-centered OSC successfully predicts morphological priming magnitudes beyond currently existing psycholinguistic metrics. The project makes use of dimensionality reduction, semantic distance calculation, linear regression and mixed effects modeling, and additionally demonstrates my JavaScript skills, which I learned for the purpose of administering the experiment remotely when in-person experiments were restricted due to COVID-19. Project motivation and results are summarized in StevensPlaut_WoW2021poster.PDF. More detailed descriptions and discussions can be found in Chapters 5-8 of my dissertation.
